# 🍔 FOODIZ — Fresh. Fast. Delicious.

A modern, responsive fast-food restaurant website built with **HTML5, CSS3, and JavaScript**.

FOODIZ provides customers with an attractive menu, product search, category filtering, shopping cart, checkout system, customer reviews, contact information, and responsive mobile navigation.

---

### 🏠 Homepage

* Modern hero section

* Fast delivery information

## 🛒 How the Cart Works

When a customer adds a product:

```text
Product
   ↓
Shopping Cart
   ↓
LocalStorage
   ↓
Checkout
   ↓
Order Confirmation
```

The cart remains available even after refreshing the browser.
